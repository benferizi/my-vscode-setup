# Daily Workflow

## Start your day

```bash
cd ~/code
```

Check all repos:

```bash
/path/to/Personal_GitHub_Code_Command_Center/scripts/doctor.sh
```

```bash
cd ~/code/personal/project-name

```

```bash

git push
```

## Sync all clean repos

```bash
/path/to/Personal_GitHub_Code_Command_Center/scripts/sync-all.sh
```

## End your day

