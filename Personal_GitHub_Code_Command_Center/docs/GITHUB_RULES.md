# GitHub Rules

1. Do not clone repos inside repos.
2. Use `~/code/category/repo`.
3. Keep `.env` out of Git.
4. Use clear commit messages.
5. Run doctor weekly.
6. Run secret scan before pushing important work.
7. Do not force push unless you understand the risk.
8. Do not ignore dirty repos.
9. Use branches for experiments.
10. Keep README files useful.
